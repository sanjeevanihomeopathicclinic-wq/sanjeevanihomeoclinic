Deploy Sanjeevani Backend — 4 Steps

Uses your Gmail account (sanjeevanihomeopathicclinic@gmail.com) · Always free · No cold starts

1
Open Google Apps Script
Go to https://script.google.com
Sign in with sanjeevanihomeopathicclinic@gmail.com
Click + New Project
2
Paste the backend code
In the editor, select all existing text and delete it.
Then open this link and copy all the code:
https://github.com/sanjeevanihomeopathicclinic-wq/sanjeevanihomeoclinic/blob/master/backend-gas/Code.gs
Paste it into the Apps Script editor.
Click the 💾 Save button (or Ctrl+S).
3
Deploy as Web App
In the top menu: Deploy → New deployment

Set these exactly:
 • Type: Web App
 • Execute as: Me (sanjeevanihomeopathicclinic@gmail.com)
 • Who has access: Anyone

Click Deploy → Click Authorize access → Allow all permissions.

You will see a URL like:
https://script.google.com/macros/s/AKfycbw.../exec
⚠️ Copy this URL — you need it for Step 4.
4
Paste the URL into GitHub config
Go to your GitHub file:
https://github.com/sanjeevanihomeopathicclinic-wq/sanjeevanihomeoclinic/blob/master/cms/js/config.js
Click the ✏️ pencil/edit icon (top right of the file).

Replace PASTE_YOUR_APPS_SCRIPT_URL_HERE with the URL you copied.

Scroll down → click Commit changes → Commit directly to master → Commit changes.
✅ Done! Your portals will be live at:
🩺 Doctor: sanjeevanihomeopathicclinic-wq.github.io/sanjeevanihomeoclinic/doctor/login.html
🏥 Reception: .../reception/login.html
👤 Patient: .../patient/login.html

First-time login creates the Google Sheet "SanjeevaniDB" automatically in your Drive.
